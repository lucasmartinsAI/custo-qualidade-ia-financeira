Para calcular a Duration de Macaulay, precisamos primeiro entender o conceito e como aplicá-lo neste cenário. A Duration de Macaulay é uma medida que indica a sensibilidade da taxa de juros ao longo do tempo. Ela é calculada como a média ponderada dos períodos de tempo até o vencimento de cada fluxo de caixa, onde os pesos são os valores descontados do fluxo de caixa.

Vamos seguir os passos:

1. **Calcular o valor do cupom de juros**:
   - O valor do cupom de juros é R$ 1.000,00.
   - O cupom de juros é de 11% ao ano, ou seja, R$ 110,00 (1.000 * 0,11).

2. **Calcular o valor do cupom de juros descontado**:
   - O cupom de juros é pago anualmente, então o valor do cupom de juros descontado é R$ 110,00.
   - O cupom de juros é pago ao final de cada ano, então o valor do cupom de juros descontado é R$ 110,00.

3. **Calcular o valor do cupom de juros descontado para cada ano**:
   - Ano 1: R$ 110,00
   - Ano 2: R$ 110,00
   - Ano 3: R$ 110,00
   - Ano 4: R$ 110,00
   - Ano 5: R$ 110,00

4. **Calcular o valor do cupom de juros descontado para cada ano, descontado à taxa de desconto de 11% ao ano**:
   - Ano 1: R$ 110,00 / (1 + 0,11)^1 = R$ 99,01
   - Ano 2: R$ 110,00 / (1 + 0,11)^2 = R$ 89,00
   - Ano 3: R$ 110,00 / (1 + 0,11)^3 = R$ 79,96
   - Ano 4: R$ 110,00 / (1 + 0,11)^4 = R$ 71,89
   - Ano 5: R$ 110,00 / (1 + 0,11)^5 = R$ 64,67

5. **Calcular a soma dos valores descontados**:
   - Soma = R$ 99,01 + R$ 89,00 + R$ 79,96 + R$ 71,89 + R$ 64,67 = R$ 384,53

6. **Calcular a soma dos valores dos cupons de juros**:
   - Soma = R$ 110,00 + R$ 110,00 + R$ 110,00 + R$ 110,00 + R$ 110,00 = R$ 550,00

7. **Calcular a Duration de Macaulay**:
   - Duration = Soma dos valores descontados / Soma dos valores dos cupons de juros
   - Duration = R$ 384,53 / R$ 550,00 = 0,7037

8. **Converter a Duration para anos**:
   - Duration = 0,7037 / 0,11 (taxa de desconto) = 6,4064 anos

**RESPOSTA: 6,40 anos**
